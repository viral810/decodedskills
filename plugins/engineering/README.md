# Engineering

Engineering skills for agentic software development.

This plugin is an empty scaffold. No skills, hooks, agents, or MCP servers ship yet.

Add original skills under `skills/<name>/SKILL.md`, following the repository’s [contribution guide](../../CONTRIBUTING.md).

Install from the `decodedskills` marketplace as `engineering@decodedskills`. See the [repository README](../../README.md) for host-specific commands.
